# LLM·RAG 실습실

### 👉 **바로 열기 — https://trmoo.github.io/llm-rag-lab/**

글을 숫자로 바꾸는 일에서 출발해 **내 문서로 답하는 AI(RAG)** 와 **스스로 판단하는 에이전트** 까지,
브라우저에서 직접 돌려 보며 익히는 학습 앱입니다.

고등학생·대학생이 처음 읽어도 따라올 수 있게 쓰되, 더 알고 싶은 사람을 위해
**「🔬 더 깊이」** 접이식 상자에 심화 서술을 따로 담았습니다.

- 화면 **30개** · 이해도 확인 문제 **95개** · 심화 상자 **27개** · 파이썬 예제 상자 **18개**
- **API 키도 인터넷도 필요 없습니다.** 계산이 전부 브라우저 안에서 끝납니다.
- 개인정보를 한 글자도 받지 않습니다. 이름·학번 칸이 없고 서버도 없습니다.

## 무엇이 진짜로 계산되고, 무엇이 흉내인가

학습 앱에서 가장 중요한 것은 **무엇을 믿어도 되는지** 아는 것입니다. 앱 안 「배움 지도」 화면에도 같은 표가 있습니다.

| 화면 | 실제로 하는 일 | |
|---|---|---|
| TF-IDF·코사인 유사도 | 수식 그대로 계산 | ✅ 진짜 |
| 감성 분류기 | 나이브 베이즈·로지스틱 회귀를 브라우저에서 학습 | ✅ 진짜 |
| 단어 임베딩 | Skip-gram + 네거티브 샘플링을 실제로 학습 | ✅ 진짜 |
| Self-Attention | 행렬 곱과 softmax 를 그대로 계산 | ✅ 진짜 |
| 그래프·에이전트 | 상태·분기·반복·체크포인트가 실제로 동작 | ✅ 진짜 |
| 다음 낱말 예측기 | 문장 50개로 만든 n-gram 모델 (진짜지만 아주 작음) | ⚠️ |
| 한국어 형태소 분석 | 사전과 규칙으로 만든 교실용 분석기 | ⚠️ 실제 도구와 다를 수 있음 |
| 문장 임베딩 | 뜻이 가까운 낱말을 미리 묶은 24차원 「뜻 지도」 | ⚠️ 원리는 같고 규모가 다름 |
| RAG 의 답 만들기 | 찾은 조각에서 근거 문장을 뽑아 조립 | ❌ 진짜 LLM 아님 |

흉내인 화면에는 **노란 상자로 그 사실을 다시 알려 줍니다.**
진짜 모델을 붙이는 방법은 각 화면의 **「🐍 파이썬으로는」** 칸에 코드로 적어 두었습니다.

## 개발자용

```bash
npm install       # 의존성 설치
npm start         # 개발 서버 (index.html 이 메인 페이지)
npm run build     # dist/index.html 한 파일로 빌드
npm test          # 계산·자료 검증 188가지
npm run check:syntax   # 소스 전수 문법 검사
```


### 지켜야 할 것

- **화면 모듈에서 `window.addEventListener('resize', …)` 나 `setInterval` 을 직접 쓰지 말 것.**
  탭을 오갈 때 리스너·타이머가 쌓입니다. `ui.js` 의 `onResize()` · `screenInterval()` 을 쓰세요.
  `npm test` 가 이것을 검사합니다.
- **채점이 붙는 고르기는 `choicePicker` 를 쓸 것.** `pillGroup` 은 첫 항목이 기본 선택이라
  학생이 안 고르고 [확인] 을 눌러도 골라진 것으로 처리됩니다.
- **`npm test` 는 탭 파일을 불러오지 않습니다**(DOM 이 없어서). 그래서 빌드 전에
  `npm run check:syntax` 로 전수 문법 검사를 함께 돌립니다. 배포 워크플로에도 들어 있습니다.
- 화면에 적어 둔 숫자를 고칠 때는 `test/*.test.mjs` 의 기대값도 함께 고치세요.
  **학생이 보는 숫자와 계산 결과가 다른 것이 가장 나쁩니다.**
